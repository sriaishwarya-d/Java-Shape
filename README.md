Java Shape Calculator

A simple Java program that calculates the area of different shapes using an abstract class and inheritance.

Features
Calculate the area of a rectangle
Calculate the area of a circle
Calculate the area of a triangle
User input for selecting the shape
Shape-specific area calculation
Concepts Used
Abstract Class
Inheritance
Constructors
Method Overriding
Classes and Objects
Scanner for user input
Conditional Statements
How It Works

The program defines an abstract shape class containing common values and an abstract calcArea() method. The rectangle, circle, and triangle classes extend the shape class and provide their own implementations of the area calculation.

The user selects a shape and enters the required dimensions. The program then calculates and displays the corresponding area.

How to Run
Make sure Java is installed on your computer.
Open a terminal in the project folder.
Compile the program:
javac shapeDemo.java
Run the program:
java shapeDemo
